# Registro de evidencias

- [Plantilla Markdown](plantilla.md).
- [Aplicación](app/index.html), al servir por HTTP la fase 01 completa.
- [Aplicación publicada](https://cia2000.github.io/dcu-templates/01-investigate/registro-de-evidencias/app/).

Adapta el registro oficial separando fuente, hecho, cita, contexto, interpretación y confianza, con una columna Real o Simulada. La aplicación no asigna IDs de evidencia: conserva los de la secuencia del proyecto y comprueba que no se repitan.

Una hipótesis no se convierte en evidencia por recibir un ID. No incluyas identidades, datos sensibles ni originales; utiliza referencias restringidas y recuerda que un código seudonimizado no garantiza anonimato.

Consulta la [guía de la fase](../README.md) y las [funciones comunes del editor](../app/README.md). El borrador es propio de esta herramienta. La importación sustituye, no combina, las respuestas y exige conservar títulos, etiquetas y tablas; no admite cualquier Markdown.
