# Análisis de tareas y contexto

- [Plantilla Markdown](plantilla.md).
- [Aplicación](app/index.html), al servir por HTTP la fase 01 completa.
- [Aplicación publicada](https://cia2000.github.io/dcu-templates/01-investigate/analisis-de-tareas-y-contexto/app/).

Adapta el análisis oficial con persona, objetivo, contexto, pasos actuales y excepciones. Las columnas de decisiones y fundamento permiten indicar bifurcaciones y distinguir hechos, relatos, hipótesis y simulaciones. Las oportunidades son mejoras por explorar, no requisitos cerrados.

Los números de pasos se ajustan al añadir o eliminar filas. Revisa manualmente las referencias a pasos escritas dentro de decisiones y retornos: la herramienta no genera un diagrama ni valida su lógica.

Consulta la [guía de la fase](../README.md) y las [funciones comunes del editor](../app/README.md). El borrador es propio de esta herramienta. La importación sustituye, no combina, las respuestas y exige conservar títulos, etiquetas y tablas; no admite cualquier Markdown.
