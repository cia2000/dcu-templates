# Guion de investigación

- [Plantilla Markdown](plantilla.md).
- [Aplicación](app/index.html), al servir por HTTP la fase 01 completa.
- [Aplicación publicada](https://cia2000.github.io/dcu-templates/01-investigate/guion-de-investigacion/app/).

Adapta el guion oficial con preparación, inicio, preguntas o tareas, seguimientos y cierre. Las filas variables se numeran automáticamente. Las orientaciones no son respuestas ni un cuestionario obligatorio: se adaptan al método y objetivo del estudio.

Prever la confirmación de consentimiento no demuestra que se haya obtenido. No incluyas identidades ni respuestas de participantes; las evidencias se documentan aparte con su autorización y contexto.

Consulta la [guía de la fase](../README.md) y las [funciones comunes del editor](../app/README.md). El borrador es propio de esta herramienta. La importación sustituye, no combina, las respuestas y exige conservar títulos, etiquetas y tablas; no admite cualquier Markdown.
