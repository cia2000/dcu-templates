# Plan de investigación y consentimiento

- [Plantilla Markdown](plantilla.md).
- [Aplicación](app/index.html), al servir por HTTP la fase 01 completa.
- [Aplicación publicada](https://cia2000.github.io/dcu-templates/01-investigate/plan-investigacion-y-consentimiento/app/).

Adapta el plan oficial para definir preguntas, método, participantes, datos, riesgos e información previa. El control de sesiones distingue lo previsto, simulado y real, sin incorporar comprobantes personales. Completar el documento no obtiene consentimiento ni determina por sí mismo la base jurídica; deben aplicarse los protocolos pertinentes antes de recoger datos reales.

No escribas identidades, firmas, respuestas ni datos sensibles. La autorización de grabación es específica y no se presume a partir de la participación.

Consulta la [guía de la fase](../README.md) y las [funciones comunes del editor](../app/README.md). El borrador es propio de esta herramienta. La importación sustituye, no combina, las respuestas y exige conservar títulos, etiquetas y tablas; no admite cualquier Markdown.
