# Plantillas y herramientas del ciclo DCU

Estos recursos acompañan al [anexo de estructura y flujo](referencias/estructura-flujo-dcu.md). Se organizan por fase y adaptan las plantillas del catálogo oficial para su uso docente; no sustituyen ese catálogo ni crean nuevas convenciones de artefactos.

## Aplicación publicada

- [Página de entrada](https://cia2000.github.io/dcu-templates/).
- [Completar el brief del problema y del ciclo](https://cia2000.github.io/dcu-templates/01-investigate/app/).
- [Las cinco herramientas de la fase 01](https://cia2000.github.io/dcu-templates/01-investigate/): brief, plan y consentimiento, guion, evidencias y análisis de tareas.

Publicación estática en GitHub Pages desde la rama `main`, raíz. `.nojekyll` mantiene los archivos Markdown sin transformarlos. No se envían respuestas a servidores ni a Canvas.

Las referencias incluidas son copias de distribución de los recursos docentes. Se han adaptado los enlaces relativos para que la publicación sea autónoma, sin cambiar los campos ni las reglas de la plantilla. La estructura del formulario se sigue obteniendo de un único archivo Markdown.
