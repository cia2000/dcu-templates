# Registro de evidencias de investigación

## Finalidad

Conserva observaciones, citas, respuestas y hechos recogidos durante la investigación, separándolos de las interpretaciones y decisiones posteriores.

## Guía de uso

1. Asignar un identificador no personal a cada sesión o fuente.
2. Registrar hechos observables y citas literales cuando aporten contexto.
3. Añadir interpretación como elemento separado y enlazarla con su evidencia.

## Plantilla

```markdown
# Registro de evidencias: [ciclo]

| ID | Fuente o sesión | Evidencia observada | Cita, si aplica | Contexto | Interpretación inicial | Confianza |
| --- | --- | --- | --- | --- | --- |
| EV-01 | [Participante P-01] | [Hecho] | [ ] | [ ] | [ ] | [Alta / Media / Baja] |

## Notas de protección de datos

- Identificadores anonimizados: [ ]
- Ubicación de registros originales: [Acceso restringido]
- Fecha de borrado o revisión: [ ]
```

## Criterios de revisión

- Las evidencias pueden rastrearse hasta una fuente permitida.
- Las interpretaciones no se presentan como hechos.
- El documento no contiene datos personales innecesarios.
