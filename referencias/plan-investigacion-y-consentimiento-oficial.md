# Plan de investigación y consentimiento informado

## Finalidad

Organiza una investigación proporcionada al ciclo y asegura que las personas participantes conocen el propósito, tratamiento de datos y carácter voluntario de su participación.

## Guía de uso

1. Definir preguntas de investigación antes de elegir técnica y participantes.
2. Recoger solo datos necesarios y limitar quién accede a ellos.
3. Obtener consentimiento antes de registrar respuestas, audio o imágenes.

## Plantilla

```markdown
# Plan de investigación: [título]

| Campo | Contenido |
| --- | --- |
| Preguntas de investigación | [ ] |
| Método | [Entrevista, observación, encuesta u otro] |
| Participantes previstos | [Perfil y número] |
| Datos recogidos | [ ] |
| Duración y lugar | [ ] |
| Responsable | [ ] |
| Riesgos y mitigación | [ ] |

## Consentimiento informado

- Propósito de la actividad: [ ]
- Participación voluntaria y derecho a retirarse: [ ]
- Datos recogidos y uso previsto: [ ]
- Conservación y acceso: [ ]
- Autorización de grabación, si aplica: [Sí / No]
- Aceptación de la persona participante: [Fecha y mecanismo acordado]
```

## Criterios de revisión

- Cada método responde a una pregunta concreta.
- El consentimiento es comprensible y anterior a la recogida de datos.
- No se solicitan datos personales innecesarios.
